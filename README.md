# 🚀 AI-Powered Career Intelligence Platform 

An intelligent, data-driven career counseling and progression platform built for students, job seekers, and career changers. Designed for the Smart India Hackathon (SIH) 2025 initiative.

---

## 🌟 Key Features

1. **Secure Authentication & User Profiles**
   - User registration and login powered by **Supabase Auth**.
   - Session management and protected dashboard access.

2. **AI-Powered Career Recommendations**
   - Matches candidate strengths with high-demand tech roles (AI/ML Engineer, Cloud Architect, Data Strategist).
   - Real-time match scoring and salary benchmarks.

3. **Interactive Career Tree & Roadmap**
   - 4-stage visual progression from foundational computing to industry mastery.
   - Curated milestone resources and project recommendations.

4. **Diagnostic Aptitude Assessment**
   - Real-time quiz calibrating analytical and engineering problem-solving skills.

5. **Intelligent College & Opportunity Finder**
   - Fast filtering for top institutes (IITs, IIITs, BITS) offering specialized AI curricula.

---

## 🛠️ Tech Stack

- **Frontend:** React 18, Vite, Modern CSS3 (Dark Theme)
- **Backend & Database:** Supabase (Auth, PostgreSQL)
- **Icons & UI:** Lucide React
- **Hosting / Dev:** Local Vite Dev Server (`http://localhost:5173/`)

---

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/your-username/ai-career-intelligence-platform.git
cd ai-career-intelligence-platform
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure Supabase Environment Variables
Create a `.env` file in the project root:
```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key-here
```

### 4. Run the development server
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.
