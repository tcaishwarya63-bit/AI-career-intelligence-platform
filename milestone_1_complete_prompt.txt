[SYSTEM CONTEXT & ROLE]
You are working on "CareerCast" (also referred to as "CareerInfinity"), a full-stack, AI-powered Career Path Prediction and Recommendation System built as an academic capstone / Smart India Hackathon (SIH) 2025 project.

The platform ingests unstructured resumes (PDF/DOCX/TXT), extracts candidate technical entities using Natural Language Processing (SpaCy Named Entity Recognition), classifies career trajectories with probabilistic machine learning models, calculates skill gap diagnostics against employer benchmarks, and persists all student records in a cloud PostgreSQL database.

   - File: ml/resume_parser.py
   - Extracts 4 entity classes: Technical Skills, Job Titles, Degrees, Educational Institutions.
   - Hybrid architecture: Statistical language model (en_core_web_sm) + custom pattern EntityRuler.
   - Requirement: >=90.0% precision on held-out resumes.

   - Real-time form fields: Technical Skills, Job Role, Degree, Institution, Target Role.
   - Connected directly to Supabase cloud database with validation and auto-sync.

3. Baseline Logistic Regression Career Classifier:
   - Files: ml/dataset.py, ml/train_baseline.py
   - Dataset: 400 historical career transition profiles across 5 key industry tracks:
     * Data Scientist
     * Software Engineer
     * Business Analyst
     * DevOps / Cloud Architect
     * Product Manager
   - Feature Engineering: TF-IDF n-gram vectorizer with L2 regularization.
   - Saved Models: ml/model.joblib and ml/vectorizer.joblib
   - Requirement: >=65.0% Top-1 Accuracy on validation split.
   - Result: 100.0% Top-1 Accuracy, 100.0% Top-2 Accuracy, and 1.00 Macro F1-score across 100 validation resumes (Benchmark PASSED).

4. Initial Career Prediction Report:
   - Files: ml/predict.py, FastAPI /predict endpoint, src/App.jsx
   - Outputs top predicted career with calibrated probability bars and coverage metrics.
   - Results are automatically logged into the Supabase PostgreSQL database.

3. CHEAT SHEET: HOW TO RUN & VERIFY THE PLATFORM
--------------------------------------------------------------------------------
* Start Vite Frontend Dev Server:
    cmd /c npm run dev
    Access locally:   http://localhost:5173/
    Access on Wi-Fi:  http://10.75.41.14:5173/

* Start FastAPI Python Backend Server:
    python -m uvicorn server:app --app-dir ml --host 0.0.0.0 --port 8000
    Interactive Swagger Docs: http://localhost:8000/docs

* Retrain Milestone 1 Baseline Model:
    python ml/train_baseline.py

* Retrain Milestone 2 Ensemble Models (LR, RF, XGBoost):
    python ml/train_ensemble.py

* Run End-to-End Prediction CLI:
    python ml/predict.py

* Re-generate PowerPoint Presentation:
    python build_white_ppt.py

* Verify Frontend Production Build:
    cmd /c npm run build

* Git Version Control (Branch: main):
    git status
    git push origin main
    Live Repository: https://github.com/tcaishwarya63-bit/AI-career-intelligence-platform
